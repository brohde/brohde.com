The input face: mono vs Circular

This is the one genuinely contested call, so here it is side by side, same line, same panel. Mono reads like a command line: fixed widths, a machine waiting for a command. Circular reads like a person typing a sentence. Recommendation: Circular Book, 16px. The material already carries the screen identity (night ground, mint, glow); the type does not need to.

Why the light panel still feels like the site. Same geometry (12px radius, docked composer, assistant rail, the [clear] token), same golden-hour atmosphere carried into the shadow and the top-corner wash, the same deep-green accent the rest of the light theme already uses. What changes: the ground is warm paper, the scanlines are gone (they read as dirt on paper), and the ink is the light palette. Night is a screen glowing in a dark room; day is a warm page in the last hour of sun. One object, two times of day.

04

A conversational contact flow

New scope. Starting a contact-like message, or invoking contact, always collects the same three things in order: name, then email, then message, then it confirms. It runs inside the chat, in the same voice, so contact never leaves the conversation. The composer placeholder becomes the current ask, and the assistant carries the prompt and any correction. The flow replaces publishing Brian's address, so the sent state shows where he will reply to you, never his own email.
