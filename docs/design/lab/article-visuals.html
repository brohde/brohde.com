Article visuals for the C world

The Option C page already speaks two materials: paper (Circular, follows the visitor's light or night ground) and screen (the always-night phosphor slab: the tide band, the [home] chips, code fences). Article imagery adds no third language. Every figure declares which material it belongs to, so a diagram, a screenshot, and a metric all feel authored by one hand.

The rule that decides every figure: a diagram is the machine explaining itself, so it is a screen object (phosphor mono, drawn in-house as inline SVG/HTML). A screenshot or archival still is evidence the writer is showing you, so it is a paper object, mounted on an editorial plate. A handful of numbers that carry the argument use the lifted card the stat band already established: paper surface, mono phosphor numerals. No charts unless data genuinely needs a shape.

Screen · diagrams

Always night: #0b110e ground, #33523f rule, #7ee787 phosphor, faint glow + scanline. Mono labels. Same material as the tide band and code fences. Identical in both grounds.

Paper · plates

Screenshots and stills. Matte --well mount, hairline --line frame, no drop shadow. Follows the theme. Bright shots get reined in on the night ground so they never glare.

Lifted · the numbers

Paper surface, mono --accent numerals, tabular figures. The stat-band pattern, scaled up for before/after deltas and ledgers. Follows the theme.

01 · Diagram language: the phosphor screen object

Shown full width in the night ground (a diagram is theme-independent: it renders identically on the light page). Real content from eight-angle-ml. Every label is a real text node, so the diagram is crawlable and selectable; the whole figure carries role="img" + an aria description for LLM readers, with the human caption in the figcaption. Horizontal flow at reading width, wraps to a vertical stack below ~620px and on mobile.

03 · Archival plate: for the older big-name pieces

Facebook Newsroom (2014) and Android for Work (2015) are archival: the sites are gone. Their evidence is Wayback captures (already on hand as stills). Same editorial plate, plus a mono provenance line in the caption so a capture reads as a dated record, not a live screen. The recommendation for both older pieces is to LEAD with an in-house diagram (safe, free, on-brand) and treat any brand-chrome still as supporting evidence, flagged for provenance comfort.

And the safe, free companion that carries the piece even if brand chrome stays out: a screen-object diagram of the eight-language rollout.

Notes for the build

Performance (#70): diagrams are inline SVG/HTML, zero JS, real text labels, no webfont (mono is system stack), so they cannot move CLS or block render. Screenshots ship pre-sized (AVIF/WebP with a raster fallback), explicit width/height inside a fixed aspect-ratio box, loading="lazy" + decoding="async" below the fold; the LCP stays the title, never a figure. Accessibility / SEO / LLM: every figure is a semantic figure + figcaption; diagrams carry role="img" and an aria description while their labels remain crawlable text; screenshots get real descriptive alt. Sentence-case captions (#76), no dashes (#18), no "terminal" (#58). Coexistence with the live aurora + tide scene (#59/#74): diagrams share the tide band's exact material, so when the scene recolors the band per page, content figures should hold a canonical mint while only the ambient band re-themes.
